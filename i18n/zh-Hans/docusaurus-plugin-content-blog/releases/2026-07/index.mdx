我们很高兴宣布 openRuyi 2026 年 7 月版本正式发布。

在本次发布中，openRuyi 对软件包进行了以安全性为重点的集中更新，协同升级了内核与桌面软件栈，改进了对 RISC-V 平台的支持，并新增了大量面向开发、人工智能、虚拟化和系统管理的软件包与工具。

{/* truncate */}

## 亮点

* **RISC-V 工具链与代码生成**：在面向 RVA23 profile 构建时，Go 现在会通过 `GORISCV64=rva23u64` 选择 RVA23 profile，同时为 RVA20 构建保留正确的回退设置。GCC 15 引入了一项上游回移修复，解决自动向量化 `fmin()` 和 `fmax()` 时对 NaN 的错误处理问题。

* **内核与 RISC-V 平台集成**：我们将主线内核从 `7.1.2` 更新至 `7.1.4`，并将 LTS 内核从 `6.18.34` 更新至 `6.18.39`。补丁集与配置更新扩展了对算能、进迭时空、玄铁和 UltraRISC 系统的支持，涵盖 PCIe、USB、存储、图形、网络、ACPI 以及开发板适配等方面。

* **RISC-V 密码学与运行时性能**：OpenSSL 在版本号不变的情况下，引入了面向 RISC-V 的 SHA-256 指令调度优化，以及 AES、SM4 和 SM2 加速补丁。jemalloc 新增了 RISC-V 汇编实现路径，`rocr-runtime` 则修正了在 RVA20 系统上对 `zicbom` 指令扩展的处理。

* **桌面与图形软件栈改进**：我们将 KDE Frameworks 从 `6.26.0` 更新至 `6.27.0`，将 Plasma 从 `6.6.5` 更新至` 6.7.1`，并将 Qt 从 `6.10.1` 更新至 `6.11.1`。这些协同更新推进了面向 Wayland 的桌面软件栈，并引入了原生适配 Plasma 的登录管理器；软件包层面的修复还涉及显示启动行为。

* **加速计算与人工智能工具**：我们将 ROCm 软件栈更新至 `7.2.4`，并使其与 LLVM 22 保持一致。新增的 Triton 和 timm 软件包扩展了由发行版管理的人工智能编译与计算机视觉工作流。

* **软件包、构建与虚拟化基础设施**：RPM 从 `4.20.1` 更新至 `6.0.1`，`obs-build` 从 `20250829` 更新至 `20260623`，本次发布还新增了 `virtiofsd`。

* **TeX 与出版软件栈集成**：本次发布新增了 TeX Live 2026。相关集成工作将 TeX Live collections 拆分为便于管理的子软件包，并在 RISC-V 平台上启用了 LuaJIT 支持。

## 安全更新

* `python-aiohttp` 更新到 `3.14.1`，包含针对 [CVE-2026-54279]、[CVE-2026-34514]、[CVE-2026-34517]、[CVE-2026-54273]、[CVE-2026-54275]、[CVE-2026-34520]、[CVE-2026-54277]、[CVE-2026-34518]、[CVE-2026-54280]、[CVE-2026-34525]、[CVE-2026-54278]、[CVE-2026-34513]、[CVE-2026-47265]、[CVE-2026-54276]、[CVE-2026-34993]、[CVE-2026-34516]、[CVE-2026-50269]、[CVE-2026-34519]、[CVE-2026-34515]、[CVE-2026-22815] 和 [CVE-2026-54274] 的修复。

* `python-authlib` 更新到 `1.7.2`，包含针对 [CVE-2026-41425] 和 [CVE-2026-44681] 的修复。

* `python-beaker` 更新到 `1.14.1`，包含针对 [CVE-2013-7489] 的修复。

* `python-curl-cffi` 更新到 `0.15.0`，包含针对 [CVE-2026-33752] 的修复。

* `python-django` 更新到 `5.2.14`，包含针对 [CVE-2026-6907]、[CVE-2026-35192]、[CVE-2026-5766]、[CVE-2026-35193]、[CVE-2026-48587]、[CVE-2026-6873]、[CVE-2026-7666] 和 [CVE-2026-8404] 的修复。

* Go 更新到 `1.26.5`，包含针对 `os.Root` 路径处理中的 [CVE-2026-39822]，以及 TLS 加密客户端问候隐私保护中的 [CVE-2026-42505] 的修复。

* NGINX 更新到 `1.31.3`，包含针对 [CVE-2026-42533] 的修复。

* `libssh` 更新到 `0.11.5`，包含针对 [CVE-2026-15370], [CVE-2026-59843], [CVE-2026-59844], [CVE-2026-59845], [CVE-2026-59846], [CVE-2026-59847], [CVE-2026-59848], [CVE-2026-59849] 和 [CVE-2026-59850] 的修复。

openRuyi 继续提供面向不同场景的四个版本：**Server**、**Container**、**Desktop** 和 **Zero（BSP validation）**。你可以前往 [openRuyi release site](https://releases.openruyi.cn/creek/2026.07/rva23/) 下载到本次发布。

现有用户只需执行 `dnf update`，即可完成升级！
