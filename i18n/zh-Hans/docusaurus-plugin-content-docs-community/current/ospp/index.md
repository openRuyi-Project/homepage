# 开源之夏

openRuyi 欢迎高校学生和社区开发者参加开源之夏 (Open Source Promotion Plan, OSPP)，在真实的开源项目中学习、协作并贡献代码。

## 什么是开源之夏

开源之夏是由中国科学院软件研究所发起的开源活动。活动联合开源组织发布项目任务，面向全球高校学生开放申请。学生中选后，在社区导师指导下完成项目开发；通过结项考核的学生可获得结项证书和劳务报酬。

2026 年起，开源之夏进入“点亮计划 2.0”，围绕 RISC-V 核心基础软件，重点关注操作系统、编译器、虚拟化和人工智能等领域。

## openRuyi 如何参与

openRuyi 通过经典模式和领航模式参与开源之夏。

| 对比项       | 经典模式                           | 领航模式                                       |
| ------------ | ---------------------------------- | ---------------------------------------------- |
| 项目如何产生 | 社区或导师预先确定具体任务         | 社区先提出需求方向，学生定义问题并设计解决方案 |
| 学生如何参与 | 选择已发布的项目并提交申请         | 围绕需求方向提交提案，通过沟通后形成具体项目   |
| 项目如何细化 | 发布前已经明确目标、要求和预期成果 | 提案入选后，由学生和导师共同细化               |
| 项目难度     | 基础、进阶                         | 基础、进阶、挑战                               |

两种模式均持续开放，不设统一的申请期或开发期。项目上线后即可申请，具体开发周期以项目详情页为准。

## 选择参与指南

- 如果你是学生，请阅读[学生参与指南](i18n\zh-Hans\docusaurus-plugin-content-docs-community\current\ospp\studentguide.md)，了解参与条件、申请流程、开发要求和结项标准。
- 如果你准备为 openRuyi 发布选题或担任导师，请阅读[导师选题发布指南](i18n\zh-Hans\docusaurus-plugin-content-docs-community\current\ospp\projectsubmissionguide.md)。

## 查看项目

前往 [openRuyi 的 OSPP 组织页面](https://summer.ospp.ac.cn/org/orgdetail/59ab01aa-4c76-4f61-834f-ac4c636267bf)查看已经发布的项目。项目将持续上线；暂时没有合适的项目时，可以稍后再次查看。

如果你对 openRuyi 参与开源之夏有疑问，请发送邮件至 [contact@openruyi.cn](mailto:contact@openruyi.cn)。有关活动规则和系统操作的问题，请联系开源之夏组委会: [org@summer-ospp.ac.cn](mailto:org@summer-ospp.ac.cn)。
